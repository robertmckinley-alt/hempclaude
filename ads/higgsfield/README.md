# Higgsfield renders — one per concept (20)

Generated with Higgsfield **Marketing Studio Image** (`marketing_studio_image`, 1:1, 2k),
using PureKana's own product cutouts as reference images so the packaging is reproduced
faithfully. Headline, sub, CTA and 21+ badge are rendered in-model from the prompt.

- `2k/`    — native 2048×2048 outputs
- `1080/`  — Lanczos-downscaled 1080×1080 for AppLovin
- `_sleep-sheet.png`, `_thc-sheet.png` — QA contact sheets

Each file is the v01 hook of the matching concept in `../gen/data.js`. Cost: 2 credits per
image, 40 total. Reference media IDs are in the session log; re-upload via `media_upload`
if regenerating in a fresh session.

Same compliance posture as the generated set: no offer or price copy, 21+ on every unit,
no kid-appeal styling, Dec 11 2026 throughout.
